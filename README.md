WPF Text-to-Speech (TTS) Applicatie

Een flexibele en gebruikersvriendelijke Text-to-Speech (TTS) desktopapplicatie gebouwd met C# en WPF (.NET). Dit project is ontworpen om geschreven tekst eenvoudig en snel om te zetten in natuurlijke spraak.

🎯 Over het Project

Het doel van dit project is om een overzichtelijke en krachtige TTS-app te bieden voor Windows-gebruikers. Of je nu documenten wilt laten voorlezen, spraakbestanden wilt genereren of simpelweg wilt experimenteren met spraaksynthese: deze applicatie biedt een solide basis.

Belangrijkste functionaliteiten (Features)

🗣️ Tekst naar spraak: Converteer geselecteerde tekst direct naar gesproken audio.

🎙️ Stemselectie: Kies uit de op het systeem geïnstalleerde TTS-stemmen (SAPI5 / Windows Speech API of System.Speech / Microsoft.CognitiveServices).
(Dit wil ik nog verbeteren naar een eigen TTS-ai model.)

🎚️ Audio-instellingen: Pas de spreeksnelheid (Rate) en het volume eenvoudig aan.

Installatie & Bouwen

Kloon de repository:

git clone https://github.com/jouw-gebruikersnaam/jouw-repo-naam.git

Open het project:
Open het .sln-bestand in Visual Studio.

Restore packages & Build:
Herstel de NuGet-pakketten en bouw de solution (Ctrl + Shift + B).

Start de applicatie:
Druk op F5 om de applicatie uit te voeren.
